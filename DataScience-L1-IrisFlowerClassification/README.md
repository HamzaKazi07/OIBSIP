## 1. Project Overview

This project uses machine learning to classify iris flowers into three species: **Setosa, Versicolor, and Virginica**, based on four physical measurements.

The objective is to explore the dataset, visualise feature distributions, train classification models, evaluate their performance, and select the best-performing model based on test results.

## 2. Technology Stack

- Python
- pandas
- scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## 3. Dataset

The Iris dataset is loaded directly from `sklearn.datasets.load_iris()`, so no external dataset download is required.

- **Total samples:** 150
- **Input features:** 4
- **Target classes:** 3
- **Samples per species:** 50

The four input features are:
- Sepal length (cm)
- Sepal width (cm)
- Petal length (cm)
- Petal width (cm)

## 4. Exploratory Data Analysis (EDA)

The notebook includes:

- Dataset dimensions and data types
- Missing-value checks
- Descriptive statistics
- Species distribution counts
- Pairplot showing relationships between the four features
- Box plots comparing feature distributions across species

### Feature observations

Petal length and petal width show useful separation between species, particularly for Setosa. Sepal measurements show more overlap between some classes.

These observations are based on the dataset visualisations.

## 5. Machine Learning Methodology

The project follows these steps:

1. Load and inspect the Iris dataset.
2. Perform exploratory data analysis.
3. Split the data into training and testing sets using an **80/20 stratified split**.
4. Train two classification models:
   - Logistic Regression
   - K-Nearest Neighbours (KNN), using feature scaling
5. Evaluate both models using accuracy, precision, recall, F1-score, classification reports, and confusion matrices.
6. Compare the measured results and select the better-performing model.

## 6. Model Results

The following results were obtained using the current train-test split:

|        Model         | Test Accuracy |
|--------------------- |--------------:|
| Logistic Regression  |    96.67%     |
| K-Nearest Neighbours |    93.33%     |

### Best-performing model

**Logistic Regression** achieved the highest test accuracy of **96.67%**, correctly classifying 29 out of 30 test samples.

KNN achieved **93.33%** test accuracy, correctly classifying 28 out of 30 test samples.

Logistic Regression is selected as the best-performing model for this experiment because it achieved higher accuracy on the held-out test set. Results may differ with another split or dataset.
